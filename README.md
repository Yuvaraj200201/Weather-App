# 🌦️ Weather Application  
  A modern and responsive Weather Application built using React + Vite that fetches real-time weather data from a public API. The app automatically adapts to the system’s light and dark mode, providing a smooth and user-friendly experience.  

## 🚀 Features  
 - 🌍 Search weather by city name  
 - 📍 Displays current location weather details  
 - 🌡️ Real-time temperature and weather conditions  
 - 💧 Humidity, 🌬️ wind speed, 👀 visibility  
 - 🌊 Sea level & ground level pressure data  
 - 🌙 Automatic theme switching (Light / Dark) based on system mode  
 - ⚡ Fast performance using Vite  
 - 📱 Responsive UI for all screen sizes   

## 🛠️ Tech Stack
 - **Frontend:** React.js  
 - **Build Tool:** Vite  
 - **Styling:** Tailwind CSS   
 - **API Website:** Openweathermap.org
